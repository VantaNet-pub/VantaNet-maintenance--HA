# VantaNet Maintenance V1.3.0

Home-Assistant-App für halbjährliche Wartungsanzeigen, PIN-geschützte Bedienung, Tablet-Steuerung, Fortschrittsanzeige und Ereignisstatistik.

Neu: Statistiken/Ereignisse zurücksetzen, Termin manuell setzen, 24-h-Erinnerung anzeigen/löschen/deaktivieren, Startdialog mit Fachkraft und Standort, Dauermodi automatisch 80–120 / schnell 20–60 / manuell 1–1440 Minuten, automatische Fertigstellung, serverseitige Sperren während der Wartung, reale berechtigungsbewusste Prüfberichte (maximal drei), A4-PDF zur Übergabe mit lokalem Logo. SFRP bleibt zufällig alle 15–20 Minuten; maximal drei Ereignisse sichtbar. Details und Grenzen siehe `DOCS.md` und `TEST_REPORT.md`.

**Achtung:** Dateioperationen und Neustartsequenzen auf dem Display sind visuelle Anzeigen, keine echten Serveraktionen.

Installationsanleitung: `INSTALL.md` im Paket.
